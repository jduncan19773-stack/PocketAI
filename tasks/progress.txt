============================================================
DRIVE SIZING NOTE
============================================================
16GB USB: ~7.3GB models leaves ~7.5GB. Knowledge storage = text x 2.6
(FTS index). Practical max here ~1.5-2GB text. For a true 3GB+ KB use a
32GB drive (or drop a model). Builder reaches any size: 
  python build_knowledge.py --source hf --target-mb <N>   (needs: pip install datasets)
